# Legacy and qualitative scripts

These scripts are kept for reference only. They are not part of the maintained
thesis analysis pipeline in `Makefile`.

- `reconnection_analysis.py`: superseded by the maintained
  `../reconnection_analysis.py` (`make reconnection`), which discovers the run
  geometry from the snapshots, uses the shared `plot_style`, and adds the
  B–kappa correlation. This copy had the paths, `dt = 0.547` and the dark
  theme hard-coded; kept only for reference.
- `plot_vdf_3d.py` and `plot_moments_scatter_3d.py`: qualitative 3D particle
  visualizations. Use the maintained 2D VDF and tabulated diagnostics for
  thesis figures.
- `generar_pdf_reporte.py`: old static report generator. Current reproducible
  outputs are the per-run folders and CSV/PNG diagnostics generated by `make`.
- `mirror_physics.py`: Bz/B0 and Jx maps written for the old `build2` run
  (128x128, 75000 steps; its default steps only cover the start of a current
  run) with a hard-coded dark theme. Replaced by `structures_analysis.py`
  (`make structures`, aliased as `make mirror`), which measures the
  structures instead of only drawing them. It still imports from the parent
  folder; run it from `CodeforAnalisys/` with `PYTHONPATH=.` if needed.
